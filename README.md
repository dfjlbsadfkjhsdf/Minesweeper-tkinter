# MINESWEEPER
#### Video Demo:  <https://www.youtube.com/watch?v=4oL6-C1FVBs>
#### Description: This project is a recreation of minesweeper in python using Tkinter to display the Gui. The project opens with a window prompting the user to input the number of rows, columns and mines they would like on the board. When the user is happy with their setup, they can press the go button at the bottom of the window to begin playing. Upon clicking this button, the current widgets are destroyed and new ones are created displaying the board, number of flags the player has left to place and a restart button.

#### The user may now click on one of the tiles on the board to uncover it. When the user does this, the program checks every tile around it to see if it has a mine under it. If this is the case, it will increase the number on the tile by one. Once the program is done with this check the tile will be uncovered and the number will be visible. If this number is zero, the number will not be displayed and the program will automatically uncover all the tiles around it that are also zero; this mechanic is called auto-fill.

#### If the user clicks a tile that happens to have a mine under it, a window will be created above the already existing window informing the user that they have lost. There will also be a restart button at the bottom of this window, if the user clicks this button the board will be refreshed and the mines will be places under different tiles. (the board will keep the configuration the user chose to begin with.)

#### If the user feels that there is a mine on a specific tile, they can place a flag by right-clicking to mark the tile. If the user right-clicks the tile again the flag will be removed. The user can only place as many flags as their are mines. If the user attempts to place another flag and they have ran out of flags to place, nothing will happen.

#### Once the user has uncovered all tiles on the board that are not mines, a new window will be created above the already existing window informing the user that they have won. There will also be a restart button at the bottom of this window if the user clicks this button the board will be refreshed and the mines will be placed under different tiles. (the board will keep the configuration the user chose to begin with.)
